# Офіційний веб-портал ТОВ «БЕНГС» (Дніпро)

Корпоративний веб-сайт постачальника нерудних будівельних матеріалів (щебінь, пісок, ґрунти, ЩПС, ПГС, керамзит) у Дніпрі та Дніпропетровській області.

## Структура проекту:
- `src/` — Вихідний код фронтенду (React, Vanilla CSS, Vite)
- `public/images/` — Локальне сховище сертифікованих медіафайлів та зображень продукції
- `server.js` — Продакшн HTTP-сервер з маскуванням заголовків та безпечною роздачею статики

## Розгортання та запуск:
```bash
npm install
npm run build
npm start
```
